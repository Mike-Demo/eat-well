## Sources, APIs & technology

- **Badgeware** — the app runtime for the Pimoroni Tufty 2350 (RP2350).
  Tested in the badge.select Make web emulator.
- **Adobe Firefly** (paid plan) — generated the pixel-art splash frames,
  diet icons, and city icons; converted to code by `scripts/make_sprites.py`.
- **MapQuest** — every restaurant's QR code opens its own MapQuest place
  listing via a `mapq.st` share link.
- **Segno** — QR code matrices are precomputed at build time
  (`scripts/make_qr.py`); the badge itself has no QR library.
- **ipwho.is** — free IP geolocation behind the "Near me" city row
  (no API key needed).
- **Firecrawl** and **Browser Use** — research tooling used to verify
  listings and resolve MapQuest place pages.
- Restaurant data is a curated guide researched in October 2026. Menus and
  dietary practices change — verify directly with the restaurant.
